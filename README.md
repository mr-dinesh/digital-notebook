# Vibe Coding

Small projects, each built to fix one real annoyance in my life. I describe what I want in plain words, an AI writes most of the code, and I check it, poke it and fix what it gets wrong. Some of them work beautifully. Some of them work.

The write-ups, with the story of each one, are at [mrdee.in/vibecoding](https://mrdee.in/vibecoding/).

Monorepo: [github.com/mr-dinesh/digital-notebook](https://github.com/mr-dinesh/digital-notebook)
